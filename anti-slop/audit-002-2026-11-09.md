# Audit 002: Interaksi Panduan Mitigasi

Scope: `src/sections/MitigationSection.jsx`, its current `src/data/mitigationData.js` inputs, and reuse of `src/components/CauseDetailModal.jsx`. No application code was changed during this audit.

1. **HIGH, time-based guidance has no detail interaction (R-26).** The three phase cards expose all long descriptions inline and have no “Lihat Detail” action or modal. This conflicts with the requested concise interactive cards. See `src/sections/MitigationSection.jsx:35-128`.
2. **HIGH, risk-zone cards have no popup interaction (R-26).** Each zone currently renders its full action list as static bullets; there is no control to open the requested per-zone detail. See `src/sections/MitigationSection.jsx:130-167`.
3. **MEDIUM, the existing modal is not reusable for mitigation content yet.** `CauseDetailModal` is tailored to cause data and hard-codes “MEKANISME PEMBENTUKAN”, while mitigation needs category headings, its own list content, highlights, and zonation disclaimer. Reuse will require carefully generalizing its presentation/data interface without changing the cause modal's current behavior. See `src/components/CauseDetailModal.jsx:4-6,86-115`.
4. **MEDIUM, zonation note does not exactly match the requested text.** The current disclaimer starts with an asterisk and “Catatan Penting:” and the same exact disclaimer is not available in a zone modal because none exists. See `src/data/mitigationData.js:97`.
5. **LOW, the phase section does not match the requested compact card summary.** It currently includes all three detail descriptions and notes in each card and labels the second phase “Respon Cepat & Mandiri”, rather than exposing the supplied subtitle through a concise action card. See `src/sections/MitigationSection.jsx:35-128`.
6. **LOW, modal entrance/exit motion is not implemented.** The cause dialog has no explicit transition or reduced-motion-aware opening/closing animation to reuse. See `src/components/CauseDetailModal.jsx:75-135`.

The existing seven independent-evacuation steps remain present in `MitigationSection.jsx`; the Go Bag checklist is already absent from the dirty worktree and will not be reintroduced.

The owner selected all six findings for correction. The implemented changes and verification are recorded in [follow-up-002-2026-11-09.md](./follow-up-002-2026-11-09.md).
