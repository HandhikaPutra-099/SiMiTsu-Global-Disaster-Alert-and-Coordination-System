# Audit 001: Popup Detail Penyebab

Scope: `src/sections/CausesSection.jsx`, based on the requested modal behavior.

1. **HIGH, keyboard dialog behavior (R-32, R-39).** The popup has no dialog semantics, initial or contained focus, and focus restoration to the triggering card button. Escape closes it, but keyboard users can still tab into the page behind it. See `src/sections/CausesSection.jsx:638-693`.
2. **HIGH, detail action opens the wrong presentation.** The button labeled “Detail Penyebab” expands the full mechanism inside the card; a separate “Buka Modal” button opens the popup. This exposes long content on the main card and makes the requested action behave differently from its label. See `src/sections/CausesSection.jsx:595-637`.
3. **MEDIUM, modal requirements are incomplete.** The backdrop does not close on outside click, the panel has no max-height or internal scrolling, and the mechanism uses bullets under “Poin Edukasi Utama” rather than a numbered list under “MEKANISME PEMBENTUKAN”. See `src/sections/CausesSection.jsx:638-679`.
4. **MEDIUM, background scroll is not locked.** Opening the popup does not prevent the page behind it from scrolling, which can change the user’s scroll position while reading. See `src/sections/CausesSection.jsx:91-102,638-693`.
5. **LOW, one mechanism note differs from the supplied copy.** The volcanic card includes an extra caution claim rather than limiting the popup to the requested content. See `src/sections/CausesSection.jsx:37-43,677-679`.

The owner selected all five findings for correction. The implemented changes and verification are recorded in [follow-up-001-2026-11-09.md](./follow-up-001-2026-11-09.md).
